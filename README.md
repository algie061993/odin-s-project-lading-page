# Foundations Landing Page

A responsive landing page built with HTML5 and CSS3 as part of The Odin Project Foundations course. This project demonstrates the core principles of web development, including semantic HTML, CSS styling, layout techniques (Flexbox), and responsive design.

## 🚀 About The Project

The goal of this project was to recreate a specific landing page design provided by The Odin Project. It focuses on:
- Creating a clean, semantic HTML structure.
- Styling the page using CSS to match the provided design.
- Implementing a responsive layout that adapts to different screen sizes.
- Using external fonts and images.

### Built With
- [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)
- [Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/)

## 📋 Prerequisites

To view this project, you only need a modern web browser (Chrome, Firefox, Safari, Edge). No additional software or installation is required.
